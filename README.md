# Wiener Linien API Test

This project tests the Wiener Linien real-time API to check if it's possible to retrieve station information and delays, and display them in a simple frontend.

## Features
- Fetch stations from the Wiener Linien API
- Display real-time departure information
- Show delays for public transport

## Setup
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   python app.py
   ```

3. Open your browser and navigate to `http://localhost:5000`
